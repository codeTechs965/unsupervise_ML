# Machine Learning Project: Unsupervised ML

A Python-based machine learning project exploring machine learning concepts and practical implementation through Jupyter Notebook.

## 📌 Overview

This repository contains a Jupyter Notebook, `C_S_D.ipynb`, for exploring machine learning concepts, working with data, and implementing Python-based analytical workflows.

The project is intended to support hands-on learning, experimentation, and the development of practical machine learning skills.

## 🎯 Objectives

- Explore machine learning concepts through practical implementation.
- Work with datasets using Python.
- Understand data analysis and machine learning workflows.
- Practice implementing and evaluating machine learning techniques.
- Develop familiarity with Jupyter Notebook and the Python data science ecosystem.

## 🛠️ Technologies Used

- **Python** — Programming language
- **Jupyter Notebook** — Interactive development environment
- **NumPy** — Numerical computing
- **Pandas** — Data manipulation and analysis
- **Matplotlib** — Data visualization

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/codeTechs965/unsupervise_ML.git
```

### 2. Navigate to the project directory

```bash
cd unsupervise_ML
```

### 3. Create a virtual environment (recommended)

**Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate
```

** macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install the required libraries

```bash
python -m pip install jupyter numpy pandas matplotlib seaborn scikit-learn
```

### 5. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open `C_S_D.ipynb` and execute the cells sequentially.
